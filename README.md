# Greywood Gardens

This repository contains the source code for the live Greywood Gardens website. It is an actively maintained project: contributors can work on the site, review changes, and propose improvements through the normal Git workflow.

The site is built with React and Vite and is deployed to Cloudflare Pages. Its featured articles are served by a Pages Function backed by Cloudflare D1.

## What’s here

- Responsive garden and editorial website
- Featured articles loaded from Cloudflare D1 through `/api/articles`
- Category browsing, contact section, and accessible navigation
- Cloudflare Pages deployment configuration
